## Urban Routes — Pruebas automatizadas con Selenium

Suite de pruebas end-to-end para el flujo de pedido de taxi de Urban Routes,
usando Selenium WebDriver y el patrón Page Object Model.

### Tecnologías

- Python, Selenium WebDriver, pytest

### Instalación y ejecución

pip install -r requirements.txt
pytest test/test_urban_routes.py -v
